# 版本回归清单

每次发布时逐项验证，未勾选表示尚未检查。

- [ ] 正确登录、错误密码拒绝、退出后 API 返回 401。
- [ ] 月／周／日、翻页、今天及日期跳转正常。
- [ ] 明暗、五种色调、刷新记忆和窄屏布局正常。
- [ ] 时间点、时间段、全天、多日全天和跨午夜 CRUD 正常。
- [ ] 每日／每周及截止日正确，单次修改和取消不影响其他日期。
- [ ] 整系列操作与例外重置提示一致，过期版本返回 409。
- [ ] 重启后日程、例外、有效会话和 OAuth 刷新授权保留。
- [ ] OpenAPI 受鉴权保护，写入返回请求 ID 和审计序号。
- [ ] MCP/OAuth 的 14 个工具、读写权限、resource、PKCE、刷新和撤销正常。
- [ ] TODO 多次排期、重复例外、完成与重开、关联删除、并发冲突与事务回滚；桌面与手机双向跳转正常。
- [ ] 验收数据已清理，审计保留且哈希链有效。

备份恢复按 [维护说明](maintenance.md) 在隔离环境演练。
