# 仓库发布说明

本仓库以当前完整功能版本作为初始提交，不保留早期开发 Git 历史。作者邮箱按维护者选择保留。

## 公开内容

源码、测试、依赖锁文件、部署模板及当前文档。示例使用本机地址、`example.com` 域名、示例网段或 `REPLACE_WITH_*`，部署前按 [部署流程](deployment.md) 替换。

个人内网地址、本机绝对路径、服务器私有目录和早期部署记录不随公开版本发布。数据库 V1—V3 源文件未修改，迁移校验和依次为 `-799209981`、`-130792381`、`1889618128`。

## 私密内容

`.local/`、真实 `.env`、`private/`、密码、OAuth secret、RSA 私钥、运行日志、数据库和备份均不提交 Git。公开源码应从 Git 导出，不直接打包包含私密文件的工作目录。

发布前检查源码和全部发布引用：运行 Gitleaks，核对已知凭据及其常见编码形式，并排查真实部署地址和路径。GitHub 上旧提交的缓存清理需另行确认，不能仅凭分支历史判断。

当前验证范围见 [验证结果](verification.md)。仓库 LICENSE 尚未选定；官方隧道客户端及其许可证由部署者从官方发布包取得，仓库不包含其二进制或私密配置。
